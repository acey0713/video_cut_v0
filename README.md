# 简易视频剪辑工具 · 使用说明

一个基于 Python + PySide6 + moviepy 的轻量桌面视频剪辑软件。

> author: Acey

---

## 一、功能概览

| 功能 | 说明 |
|---|---|
| 导入视频 | 直接拖文件到窗口，或菜单选择；支持一次拖多个 |
| 视频预览 | 播放 / 暂停 / 进度拖动 / 音量调节 |
| 裁剪片段 | 对每段视频单独设入点、出点 |
| 多段拼接 | 按片段列表顺序自动合并成一个视频 |
| 调整顺序 | 在列表里直接拖动行上下调整拼接顺序 |
| 声音插入 | 在指定时间点叠加一段音频（背景音乐 / 配音 / 音效） |
| 混音控制 | 原音轨音量、插入音频音量分别可调 |
| 导出 | 一键合成 MP4 到本地 |

## 三、快速开始

### 1. 添加视频

任选一种方式：

- **拖入（推荐）**：在文件资源管理器里选中一个或多个视频文件，直接拖到软件窗口任意位置松手。
- **菜单**：文件 → 添加视频片段...（Ctrl+O），在对话框里选文件。

支持的视频格式：MP4 / MOV / AVI / MKV / FLV / WMV / WEBM。

每添加一段，它会出现在「视频片段」列表里，并自动显示该段的完整时长。

### 2. 预览并裁剪每一段

- **点击列表里某一段**，上方预览区会加载这段视频。
- 播放到想要的**开始位置**，点「**当前位置设为入点**」。
- 播放到想要的**结束位置**，点「**当前位置设为出点**」。
- 列表里这一行会实时更新为 `[入点 ~ 出点] (实际时长)`。

> 不裁剪也行：默认入点=0、出点=视频全长，导出时就是完整片段。

### 3. 调整拼接顺序

- 在片段列表里，**按住某一行上下拖动**，拖到目标位置松手即可。
- 列表最上面的片段在导出视频的最前面。
- 选错了就选中那行，点「删除选中」移除。

### 4. 插入声音（核心功能）

- **拖入音频文件**，或点「+ 添加音频...」。支持 MP3 / WAV / M4A / AAC / FLAC / OGG。
- 每段插入音频会显示：
  - **@ [时间]**：从拼接完成后的成片第几秒开始播放这段音频。
  - **音量滑块**：这段插入音频自身的音量（0 ~ 2.0）。
- 可以加多段，分别设在不同时间点、调不同音量。
- 「原音轨音量」滑块控制原视频声音大小（0 ~ 2.0）。

> 混音方式：**叠加**。原音轨和插入音频同时存在，导出后都能听到。
> 预览窗口播的是当前选中片段的原声音；混音效果在导出后的视频里体现。

### 5. 导出

- 菜单：**文件 → 导出视频...**（Ctrl+E）。
- 选保存位置，默认文件名形如 `edited_20260919_153000.mp4`。
- 导出过程中会显示"正在导出"窗口，大文件需要等一会。
- 完成后弹窗提示保存路径。

## 四、典型场景

### 场景 A：两段视频首尾相接合并
1. 拖入视频 A 和视频 B
2. 直接点导出 → 得到 A 接 B 的完整视频

### 场景 B：裁剪 + 拼接
1. 拖入视频 A，选中它，播到 00:03 点设入点，播到 00:10 点设出点
2. 拖入视频 B，同样裁出你要的片段
3. 导出 → 得到 A 的片段 + B 的片段

### 场景 C：加背景音乐
1. 拖入要拼接的视频
2. 拖入背景音乐 MP3
3. 插入时间设为 0.00，音量调到 0.3（不压过人声）
4. 把「原音轨音量」保持 1.0
5. 导出 → 原视频声音 + 背景音乐叠加

### 场景 D：替换视频原音（几乎静音）
1. 拖入视频
2. 把「原音轨音量」拉到 0
3. 插入你想要的配音/音频，设好时间和音量
4. 导出 → 只有新插入的声音

## 六、常见问题

**Q：拖视频进窗口没反应？**
A：确认拖的是视频文件本身（不是文件夹），格式在支持列表里。软件会过滤其他类型文件。

**Q：导出特别慢？**
A：导出需要重新编码视频（尤其分辨率高、时长长时），这是正常的。预览快是因为只是播放文件，导出才是真正合成。

**Q：导出的视频没有声音？**
A：检查「原音轨音量」是不是拉到 0 了；确认你的源视频本身有音轨。

**Q：插入的音频在导出视频里听不到？**
A：检查插入时间是不是落在视频时长范围内；音量是不是 0；原视频是不是太短，音频还没播放完视频就结束了。

**Q：不同分辨率的视频能拼一起吗？**
A：可以。软件会自动以第一段视频的尺寸为基准，其他段自动适配。

## 七、技术栈

- Python 3.14
- PySide6 6.x（GUI）
- moviepy 2.x（视频剪辑）
- imageio-ffmpeg（内置 ffmpeg，无需单独安装）
- PyInstaller（打包 exe）
